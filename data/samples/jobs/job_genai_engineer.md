Senior Generative AI Engineer - Harborline Logistics

About the role
Harborline is building an assistant that helps dispatchers answer shipment questions from contracts, SOPs and live tracking data.

Responsibilities
- Build retrieval-augmented generation pipelines over contracts and operating procedures.
- Implement tool calling against the tracking and billing APIs with strict permission checks.
- Evaluate answer quality with labelled datasets and track latency, token usage and cost.
- Deploy services on AWS using Docker, ECS and GitHub Actions.

Requirements
- 5+ years of experience building backend services in Python.
- Hands-on experience with LLMs, AWS Bedrock, embeddings and vector search (pgvector or OpenSearch).
- Experience with FastAPI, PostgreSQL and CI/CD.
- Familiarity with prompt injection risks and guardrails.

Benefits
Hybrid work from Columbus, OH. Medical, dental and a learning budget.
